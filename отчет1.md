#Цели

- Познакомиться с основами рекуррентных соотношений и динамического программирования.
- На примере модели Фибоначчи реализовать вычисление численности популяции кроликов с учётом заданных условий.
- Научиться применять программирование для решения реальных биологических задач.

#Задачи

- Реализовать функцию для вычисления числа пар кроликов на n-й месяц при условии, что каждая взрослая пара рождает k пар новорождённых.
- Использовать рекуррентное соотношение, учитывающее предыдущие значения последовательности.
- Обеспечить корректный ввод и вывод данных.

#Инструменты

- Язык программирования Python.
- Использование списков для хранения промежуточных результатов.
- Циклы и условия для реализации рекуррентного вычисления.

#Алгоритмы

- Используется динамическое программирование для вычисления n-го члена последовательности.
- Формула рекуррентного отношения:
  f[n] = f[n-1] + k * f[n-2], где
  - f[1] = 1 — в первый месяц есть одна пара кроликов,
  - f[2] = 1 — во второй месяц репродуктивный возраст ещё не достигнут,
  - k — число пар новорождённых от каждой взрослой пары.

#Ошибки
Ошибка: Невнимание к индексации месяцев (месяцы начинаются с 1, а не 0). Исправление: Создание списка размером n+1 для удобства работы.

- Программное решение позволяет быстро и эффективно вычислять численность популяции для больших значений месяцев.
