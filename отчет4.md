
#Задание 1. Формирование исходного файла

#Цель:
Получить GenBank-файлы для двух биологических видов с сайта NCBI и объединить их в один файл.

#Задачи:
- Сделать запросы к базе NCBI по названию вида с параметром complete cds.
- Скачать по 5 записей для каждого вида в формате GenBank.
- Объединить скачанные записи в один файл.

#Инструменты:
- Python
- Biopython (модуль Entrez и SeqIO)
- Интернет для доступа к NCBI

#Алгоритм:
1. Использовать Entrez.esearch для поиска идентификаторов записей по запросу "название_вида" AND complete cds.
2. С помощью Entrez.efetch скачать записи по найденным ID в формате GenBank.
3. Сохранить записи каждого вида.
4. Объединить записи двух видов в один файл с помощью SeqIO.write.
#Ошибки
- Нет интернета или блокировка запроса — проверить подключение, указать email в Entrez.
- Пустой результат поиска — проверить корректность запроса.
- Ошибки чтения/записи файла — проверить права доступа и корректность путей.
#Задание 2. GC-составы

#Цель:
Прочитать объединённый файл GenBank, извлечь CDS и вывести их GC-составы в порядке возрастания.

#Задачи:
- Считать объединённый файл.
- Для каждой CDS вычислить GC-состав.
- Отсортировать CDS по GC-составу.
- Вывести ID записи и GC-состав.

#Инструменты:
- Python
- Biopython (SeqIO и работа с features)

#Алгоритм:
1. Считать записи из объединённого файла с помощью SeqIO.parse.
2. Перебрать все признаки (features) и выбрать только CDS.
3. Извлечь последовательность CDS и посчитать GC-состав.
4. Сохранить данные в список.
5. Отсортировать список по GC.
6. Вывести в нужном формате.
#Ошибки
- Отсутствие CDS у некоторых записей — добавить проверку. 
- Пустые или некорректные последовательности — проверять длину перед расчетом GC. 
- Ошибки чтения файла — проверить путь и формат.

#Общий вывод

- Разделение задачи на этапы — получение данных и их анализ — упрощает разработку и отладку. 
- Важно тщательно обрабатывать ошибки, связанные с сетью, форматом данных и отсутствием нужных признаков. 
- Анализ GC-составов помогает выявить биологические особенности кодирующих последовательностей.
